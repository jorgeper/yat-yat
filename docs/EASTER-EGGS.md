# Yat Yat's secrets 🥚

You found the spoilers page. Three eggs ship in the app; none of them ever
touch your dictation — they're pure decoration, and they all calm down if
your system has Reduce Motion on. Want zero surprises? Settings → General →
**Easter eggs** switches all three off.

## 1. Tell it to dance

Say **"dance"** while dictating (with live transcription on) and both the
pill *and* the menu-bar icon do a happy little wiggle. Any sentence works —
"I have dance class tonight" counts; the app is not picky about being
invited.

(It used to answer to its own name, but speech models flatly refuse to
believe "yat" is a word — they hear "that you add", which wiggles nothing.
"Dance" they believe.)

## 2. ↑ ↑ ↓ ↓ ← → ← → B A

Type the Konami code anywhere in the Settings window (not while focused in
a text field) and a **13th theme** unlocks: **Yat95** — beveled gray,
navy-on-silver, a lovingly period-accurate tribute. It never appears in
the Appearance picker; the code is the only door. Enter the code again to
go back to whatever theme you had.

## 3. Let it sleep

Open the dictation pill and say nothing for **20 seconds**. The waveform
gives up: the bars slump flat and a little 💤 drifts up. It's still
recording — everything works exactly as before — it's just bored. Any
sound wakes it instantly.
